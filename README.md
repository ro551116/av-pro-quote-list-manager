# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ef6ecf83-a3d7-412d-80da-47add063882c

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## 報價編輯

- 修改欄位、器材或檔期費用後，停止輸入約 1 秒會自動儲存至伺服器，不會離開編輯頁。
- 頁首顯示等待儲存、儲存中或已自動儲存。儲存失敗時保留編輯內容，可按「重試儲存」；尚未儲存前重新整理或關閉頁面會提示確認，請勿忽略提示以免遺失變更。
- 返回箭頭與「儲存並返回」都會等待最新修改儲存成功，失敗時留在編輯頁。
- 器材名稱旁的上下箭頭可調整同一分類內的順序；第一筆不能上移、最後一筆不能下移。排序會自動儲存，報價單與器材單沿用此順序，不改變分類。
- 報價單的檔期費用只顯示名稱與金額，不顯示計費百分比；一般版、附件摘要及 PDF 一致。編輯器仍保留百分比設定，金額計算不變。

## 檔期設定

- 編輯順序為「器材 → 檔期設定 → 報價合計」。每個檔期直接列出項目，不必先展開檔期；未使用的器材分類保留新增按鈕。
- 每個檔期只有一個「新增項目」入口，不需先區分人力或車載。日期、時段、備註、工作計價、包價及報價單呈現直接顯示；項目名稱、數量與單位、工期與單位、客報單價、成本單價同列編輯，類型、內部項目、備註、搬移、排序及刪除也不藏在選單中。
- 檔期內只有較長的「適用器材」勾選清單保留一層展開，入口顯示已選／全部數量；器材計費方式、比例或金額、次數、費用日期及歸屬直接可見，不再有「設定 → 更多設定 → ⋯」。既有工期不會重設，包價項目仍標示參考小計。上方器材清單的成本、整案「成本與毛利」及「發包設定」維持原本的按需展開。單純瀏覽或展開器材清單不修改報價資料。
- 新報價預設有「進場」「活動」「撤場」，整場器材費用先歸屬「活動」；可新增、重新命名及調整檔期順序。
- 器材費用可選整檔明細加總、整檔固定包價，或依檔期計費。檔期比例只套用勾選的器材；固定金額不依賴器材選取。各段可另設計費次數，日期只供排程，不會自動乘入費用。
- 新項目預設為一般費用、1 式、1 次，可自由填寫工作人員、貨車或其他內容，類型與單位就在項目旁直接調整。既有項目保留原類型與工期，金額仍按「數量 × 天數或次數 × 單價」計算；各檔期可獨立配置，沒有工作項目時不加收費用。
- 人力與其他費用的計價、對外顯示互相獨立：「明細加總」或「人力與其他費用包價」決定收費，「展開工作明細」或「工作項目摘要」決定客戶看到的內容。包價只取代本檔期工作明細金額，不包含另列的器材費用；檔期列顯示兩者合計。
- 成本始終按實際明細計算，不隨對客包價或顯示方式改變。主器材清單的成本視為整檔成本，只計一次；階段成本按其數量及工期計算。內部項目計入成本，不出現在客戶報價。
- 檔期與明細皆可排序，明細亦可移至其他檔期。涉及固定包價時會提醒：搬動明細不會自動調整包價，需自行確認總額。
- 舊單維持原計價方式，不會自動轉換。按「使用整合檔期設定」先預覽金額；確認後保留原總價與成本，工作團隊移至「原工作團隊」供重新分配。取消不修改原單。原折扣導致工作團隊使用固定包價時，重新分配後須同步調整包價。
- 對客報價以一張「檔期與項目」表呈現：同一檔期的器材費用與工作項目列在一起，只列一個檔期小計，不再拆「器材計費項目」與「階段工項」。上方器材明細的價格僅供參考，不重複計入報價。
- 摘要附件每個檔期只列一筆合併金額；一般 PDF 與附件明細使用同一分組。包價明細只列規格與數量，金額統一由包價列計收；統包摘要仍不展開工作明細。客戶報價不顯示計費百分比、內部項目或成本。
- 成本分析、器材單、發包選項、客戶歷史與沿用報價仍使用原計價資料；這次列印分組不會改寫既有報價。
- 既有器材費用若未指定檔期，保留原名稱獨立列在清單中；可直接「新增項目」，或用旁邊的「器材費用歸屬／費用歸屬檔期」選單指定歸屬，不會重複加收。個別器材費用的日期覆寫不隨檔期日期自動更改。
- 器材費用的可選 `stageId` 只記錄歸屬，不改變原計價模式；沿用報價時重新對應識別碼。刪除檔期需確認，會移除該檔期的工作明細與使用中的器材費用，但保留主器材清單及成本；停用中的計費設定不會因刪除而重新啟用。

## 開發驗證

```sh
npm test
npm exec --no -- tsc --noEmit
npm run build
```

`npm test` 覆蓋器材計費的選取與次數、包價／成本獨立性、舊單保價轉換、檔期費用歸屬與安全刪除、沿用報價的識別碼及選取關係，以及對客分組金額一致性、避免重複計費與列印隱私邊界。
