# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ef6ecf83-a3d7-412d-80da-47add063882c

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## 報價編輯

- 修改欄位、器材或檔期費用後，停止輸入約 1 秒會自動儲存至伺服器，不會離開編輯頁。
- 頁首顯示等待儲存、儲存中或已自動儲存。儲存失敗時保留編輯內容，可按「重試儲存」；尚未儲存前重新整理或關閉頁面會提示確認，請勿忽略提示以免遺失變更。
- 返回箭頭與「儲存並返回」都會等待最新修改儲存成功，失敗時留在編輯頁。
- 器材名稱旁的上下箭頭可調整同一分類內的順序；第一筆不能上移、最後一筆不能下移。排序會自動儲存，報價單與器材單沿用此順序，不改變分類。
- 報價單的檔期費用只顯示名稱與金額，不顯示計費百分比；一般版、附件摘要及 PDF 一致。編輯器仍保留百分比設定，金額計算不變。

## 器材租賃與工作階段

- 新報價使用階段計價，預設有「進場」「活動」「撤場」，可新增自訂階段、重新命名及調整順序。
- 器材租金可選整檔明細加總、整檔固定包價，或依檔期計費。檔期比例只套用勾選的器材；固定金額不依賴器材選取。各段可另設計費次數，日期只供排程，不會自動乘入費用。
- 各工作階段可分別加入人力、車載、額外器材及其他費用。明細按「數量 × 天數或次數 × 單價」計算；不同階段不必使用相同人數。活動期間器材留場但無派駐人員時，該階段可留空，不產生人力費用。
- 階段計價方式與對外顯示互相獨立：選擇「明細加總」或「固定包價」決定收費；選擇「展開明細」或「統包摘要」決定客戶看到的內容。固定包價取代明細加總，不重複加收。
- 成本始終按實際明細計算，不隨對客包價或顯示方式改變。主器材清單的成本視為整檔成本，只計一次；階段成本按其數量及工期計算。內部項目計入成本，不出現在客戶報價。
- 階段與階段內明細皆可排序，明細亦可移至其他階段。涉及固定包價時會提醒：搬動明細不會自動調整包價，需自行確認調整後的總額。
- 舊單維持原計價方式，不會自動轉換。按「轉換為階段計價」先預覽金額；確認後保留原總價與成本，工作團隊移至「原工作團隊」供重新分配。取消不修改原單。原折扣導致工作團隊使用固定包價時，重新分配後須同步調整包價。
- 報價單、摘要附件、PDF、成本分析、器材單、發包選項、客戶歷史與沿用報價均使用同一階段資料；客戶報價不顯示計費百分比與內部成本。

## 開發驗證

```sh
npm test
npm exec --no -- tsc --noEmit
npm run build
```

`npm test` 覆蓋租金選取與次數、包價／成本獨立性、舊單保價轉換與重新分配、沿用報價的識別碼及選取關係，以及客戶列印的隱私邊界。
